# Photo Quality Engine

Engine untuk mendeteksi kualitas foto (buram, pecah, gelap), mengompres secara dinamis, dan memvalidasi keaslian foto (POD, paket, lokasi, barang), yang bisa diintegrasikan ke berbagai aplikasi PCP Express.

Status: **tahap perencanaan**. Belum ada kode.
